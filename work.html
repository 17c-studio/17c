Athletics

Basketball Tickets, Hope College

A responsive ticket-page redesign built with HTML, CSS, and JavaScript for Hope’s men’s and women’s basketball games.

Explore the project ↗ (opens in a new tab)
Behind the project +
The challenge
Help fans distinguish teams and find relevant games as the schedule changes throughout the season.
The solution
I reworked the content flow, added visual team indicators and search filters, and wrote date-based logic to separate upcoming and past games.
Project outcome
Completed games move into history automatically, keeping the main view focused on upcoming ticket options.

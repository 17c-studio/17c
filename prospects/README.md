# Prospect personalization

- Edit `prospects.json` to manage business information and personal notes.
- Add business logos to `logos/`; JSON logo values use paths such as `prospects/logos/example.png` because they resolve against the root web page.
- `prospects.js` loads the data and personalizes root pages.
- `prospect-reveal.js` controls the personalized welcome.
- [Personalized-link guide](Personal-Links-for-Prospects.md) explains the `?for=` links.

Existing prospect URLs are unchanged. See [the file guide](../docs/FILE_ORGANIZATION.md) for the full repository layout.

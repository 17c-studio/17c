# 17C Studio pages

The public page files remain at the root to preserve their URLs:

- [Home](../index.html): `js/home.js` and `css/styles.css`.
- [Services](../services.html): `js/services.js` and `css/services.css`.
- [Contact](../form.html): shared inquiry and wishlist code.
- [Work](../work.html): `js/work.js` and `css/work.css`.

`css/home-critical.css` supplies the homepage's inline first-viewport CSS. Shared features live in `../shared/`; personalized prospect behavior lives in `../prospects/`.

See [the file guide](../docs/FILE_ORGANIZATION.md) for validation and editing instructions.
